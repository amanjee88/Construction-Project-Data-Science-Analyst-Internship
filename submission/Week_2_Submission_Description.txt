This report presents an exploratory data analysis (EDA) and introductory statistical modeling workflow for construction project performance. The analysis uses a reproducible, simulated dataset containing 250 project records and 19 fields. The dataset includes project type and region, planned and actual duration, schedule delay, planned budget, simulated final cost, cost-overrun percentage, contractor experience, workforce size, equipment hours, material cost index, procurement delay, weather delay, and safety incidents. The report explicitly identifies all observations as synthetic and does not represent them as actual construction records.

The EDA section explains the data-audit process, variable groups, descriptive statistics, category-level comparisons, and interquartile-range screening for potential outliers. Five visualizations are provided and interpreted: the distribution of schedule delay, procurement delay versus schedule delay, mean delay by project type, a correlation heatmap, and planned budget versus simulated final cost. The interpretations focus on how these views can support early-warning monitoring, procurement tracking, project-level review, and budget oversight while distinguishing association from causation.

The modeling section develops two multiple linear regression examples. The first estimates schedule delay in days and the second estimates cost overrun in percentage points. Categorical project attributes are one-hot encoded, data is divided into training and test subsets, and model performance is evaluated using mean absolute error (MAE), root mean squared error (RMSE), and the coefficient of determination (R-squared). The report also explains key coefficients, assumptions, model suitability, limitations, and the weaker predictive fit of the cost-overrun model. Recommendations are included for tracking critical procurement items, reviewing schedule risk, monitoring cost-to-complete, and investigating unusual values instead of removing them automatically.

For reproducibility, the accompanying GitHub project includes the synthetic CSV, a fixed-seed data-generation script, the EDA and modeling script, summary tables, audit outputs, model metrics, coefficients, predictions, and visualization files. The analysis can be rerun from the repository root using the instructions in the project README. Because the data are simulated and the validation uses a single random train-test split, the results are educational demonstrations only; real-world use would require permissioned operational data, domain validation, repeated or time-aware testing, residual diagnostics, and review by construction professionals.
